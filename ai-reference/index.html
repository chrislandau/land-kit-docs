💡 How to Use

For Raven / AI Tools in Grasshopper:

Ask Raven to generate Land Kit scripts. Reference the manifest or specific workflows:

"Generate a Land Kit script following the basic_hydrology workflow. Reference: https://github.com/landau-design/land-kit/tree/main/docs/ai-reference"

For Developers:

Fetch the manifest to build your integration:

https://raw.githubusercontent.com/landau-design/land-kit/main/docs/ai-reference/manifest.json

The manifest provides URLs for all reference files plus implementation examples.

GitHub Raw URLs (for API access):

https://raw.githubusercontent.com/landau-design/land-kit/main/docs/ai-reference/{filename}.json

Replace {filename} with: component_registry, layer_validation, workflow_patterns, error_reference, integration_guide, or manifest
